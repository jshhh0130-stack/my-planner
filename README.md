# 데일리 플래너

매일 할 일·시간표·메모·사진을 적고, 캘린더로 일정을 조절하는 나만의 플래너입니다.
핸드폰·패드·노트북에서 같은 주소로 열고 **홈 화면에 앱으로 설치**해서 씁니다.

- 주소: https://jshhh0130-stack.github.io/my-planner/
- 예시 데이터로 둘러보기: https://jshhh0130-stack.github.io/my-planner/?demo (내 기록과 따로 저장됨)

## 화면

| 화면 | 하는 일 |
|---|---|
| **오늘** (첫 화면) | 오늘의 목표, 우선순위 10칸, 그 밖의 할 일, 05~23시 시간표, 메모·사진. 밤 12시가 지나면 자동으로 새 날 페이지로 넘어감 |
| **캘린더** | 월·주 보기. 일정을 끌어서 옮기고 길이 조절, 매일·평일·매주 반복. 옆 칸에서 고른 날의 일정·우선순위·메모를 바로 보고 적기 |
| **기록** | 지난 날 적은 것을 날짜별로 모아 보기, 검색, 메모·사진·완료한 일만 골라 보기 |

## 설치

- **갤럭시(크롬)**: 주소를 열고 → 화면의 `설치` 버튼, 또는 메뉴(⋮) → `홈 화면에 추가`/`앱 설치`
- **노트북(크롬·엣지)**: 주소창 오른쪽의 설치 아이콘

## 저장과 연동

- 기본: 각 기기 안에 저장 (인터넷 없어도 동작)
- 핸드폰·노트북·패드 실시간 연동: [SETUP.md](SETUP.md) 대로 Firebase(무료)를 한 번 연결하면 켜짐
- 설정 → 백업 내려받기로 모든 기록(사진 포함)을 파일로 보관 가능

## 업데이트

새 버전을 올리면 설치된 앱도 **다음에 열 때(또는 다시 화면에 돌아올 때) 자동으로** 바뀝니다. 다시 설치할 필요 없음.
(배포할 때 `version.json`의 숫자를 올리면 켜 둔 앱도 알아서 새로고침)
