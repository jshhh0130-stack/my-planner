# 데일리 플래너

매일 할 일·시간표·메모·사진을 적고, 캘린더로 일정을 조절하는 나만의 플래너입니다.
핸드폰·패드·노트북에서 같은 주소로 열고 **홈 화면에 앱으로 설치**해서 씁니다.

- 주소: https://jshhh0130-stack.github.io/my-planner/
- 예시 데이터로 둘러보기: https://jshhh0130-stack.github.io/my-planner/?demo (내 기록과 따로 저장됨)

## 화면

| 화면 | 하는 일 |
|---|---|
| **오늘** (첫 화면) | 왼쪽: 오늘의 목표 · 우선순위 10칸(오른쪽에 ✓ 했음 / ✗ 못함) · 그 밖의 할 일 / 가운데: 메모·사진(지난 메모까지 이어서) / 오른쪽: 05~23시 시간표. 창을 줄이면 왼쪽 목표·우선순위, 오른쪽 메모. 밤 12시가 지나면 자동으로 새 날 페이지로 넘어감 |
| **캘린더** | 월 보기는 칸마다 일정 제목, 여러 날 일정은 이어진 막대(핸드폰은 날짜를 누르면 그날 창 + 아래 "○월 ○일에 일정 추가"). 주 보기는 끌어서 옮기고 길이 조절. 일정 편집 창에서 시작→끝 기간(여러 날), 반복(매일 · 매주 요일 여러 개 · 매월)과 반복 기간 |
| **기록** | 지난 날 적은 것을 날짜별로 모아 보기, 검색, 메모·사진·완료한 일만 골라 보기, 메모 바로 고치기 |
| **펜 필기** | 시간표 제목 옆 ✎ 펜: 시간표 전체에 S펜으로 자유롭게 쓰기(손가락은 화면 이동, 손바닥 무시), 펜 색·지우개·되돌리기, 날짜별 저장·동기화 |

## 설치

- **갤럭시(크롬)**: 주소를 열고 → 화면의 `설치` 버튼, 또는 메뉴(⋮) → `홈 화면에 추가`/`앱 설치`
- **노트북(크롬·엣지)**: 주소창 오른쪽의 설치 아이콘

## 캘린더 연결

구글 캘린더(삼성 캘린더에서 구글 계정에 저장한 일정·공휴일 포함)를 시간표·캘린더에 같이 보여 줍니다(읽기 전용). 설정 방법은 [SETUP.md 6번](SETUP.md#calendar)을 보세요.

## 저장과 연동

- 기본: 각 기기 안에 저장 (인터넷 없어도 동작)
- 핸드폰·노트북·패드 실시간 연동: [SETUP.md](SETUP.md) 대로 Firebase(무료)를 한 번 연결하면 켜짐
- 설정 → 백업 내려받기로 모든 기록(사진 포함)을 파일로 보관 가능

## 업데이트

새 버전을 올리면 설치된 앱도 **다음에 열 때(또는 다시 화면에 돌아올 때) 자동으로** 바뀝니다. 다시 설치할 필요 없음.
(배포할 때 `version.json`의 숫자를 올리면 켜 둔 앱도 알아서 새로고침)
